# Protocol Independent Routing

## Overview

This repository contains a collection of smaller home labs designed to develop a deeper understanding of protocol-independent routing concepts, including different route types, load balancing, and filter-based forwarding.

Each section focuses on a specific topic and explores its concepts through practical implementation. Each lab will include a topology diagram, device configurations, and explanations of the underlying functionality.
